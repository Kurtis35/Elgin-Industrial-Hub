Diagnosis
- The build ran the Vite build inside the package folder artifacts/elgin-tool-gas (see [line 72](#L72)) and produced dist/public files inside that package (see [lines 80–82](#L80-L82)).
- Netlify is configured to publish dist/public at the repo root (resolved as /opt/build/repo/dist/public) but that directory does not exist because the build output is under artifacts/elgin-tool-gas/dist/public (see [line 102](#L102)). This mismatch causes the failing deploy: "Deploy directory 'dist/public' does not exist" (see [line 96](#L96)).

Root cause: publish directory mismatch — Netlify expects dist/public at the repo root but the build outputs to artifacts/elgin-tool-gas/dist/public.

Solution
Pick one of the two options below. Option A is the simplest.

Option A — Change Netlify publish directory (recommended)
1. Set Netlify's publish directory to the actual build output:
   - In the Netlify UI: Site settings → Build & deploy → Build settings → Publish directory: artifacts/elgin-tool-gas/dist/public
   - Or add (or update) a netlify.toml in your repo root and commit:

```toml
# netlify.toml
[build]
  command = "pnpm run build:netlify"
  publish = "artifacts/elgin-tool-gas/dist/public"
```

2. Redeploy. Confirm logs show the publish directory path and that artifacts/elgin-tool-gas/dist/public is present.

Option B — Change the build to output to the repo-level publish directory
1. Edit the Vite config in artifacts/elgin-tool-gas/vite.config.ts to set build.outDir to point to the repo-level folder (example output path relative to the package):

```ts
// artifacts/elgin-tool-gas/vite.config.ts (example)
export default defineConfig({
  build: {
    outDir: "../../dist/public", // two levels up into repo root /dist/public
    // ...other build options
  },
});
```

2. Commit and redeploy. Netlify's existing publish: dist/public will then match the produced output.

Verification
