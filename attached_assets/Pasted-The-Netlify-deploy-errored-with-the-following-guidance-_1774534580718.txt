The Netlify deploy errored, with the following guidance provided:

Diagnosis
- Relevant error lines: [lines 68–71](#L68-L71) show pnpm failing with "Missing script: build:netlify". The build command invocation is shown at [lines 76–81](#L76-L81) and the resolved Netlify config that triggers it is shown at [lines 82–86](#L82-L86).
- Error type and cause: Netlify is running the command defined in netlify.toml ("pnpm run build:netlify"), but package.json does not define a "build:netlify" script. PNPM returns ERR_PNPM_NO_SCRIPT because that script name does not exist.

Solution
1) Verify package.json is present and contains your build scripts
- Confirm package.json is committed to the repo (look at https://github.com/Kurtis35/Elgin-Industrial-Hub/blob/main/package.json).
- Open package.json and inspect the "scripts" section to see which build script(s) exist (for example "build").

2) Fix one of the two ways below (pick one)

Option A — Add a build:netlify script (recommended)
- Edit package.json and add a "build:netlify" script that delegates to your existing build script. Example change (add inside "scripts"):
```json
{
  "scripts": {
    "build": "your-existing-build-command",
    "build:netlify": "pnpm run build"
  }
}
```
- Replace "your-existing-build-command" with the actual command already used in your project (or omit if "build" already exists).
- Commit and push:
```bash
git add package.json
git commit -m "Add build:netlify script for Netlify builds"
git push
```
- Re-run the Netlify deploy.

Option B — Change Netlify build.command to an existing script
- If your package.json already has a "build" script, update netlify.toml to call that instead of build:netlify. Edit netlify.toml (repo file: https://github.com/Kurtis35/Elgin-Industrial-Hub/blob/main/netlify.toml) and change:
```toml
[build]
  command = "pnpm run build"
  publish = "dist/public"
```
- Commit and push the change, then re-run the Netlify deploy.

Notes
- Make sure package.json is indeed in the repo root (committed) before changing netlify.toml. If it is in a subfolder, update netlify.toml to cd into the subfolder first or adjust the working directory accordingly.
- After making the change, trigger a new deploy on Netlify.
